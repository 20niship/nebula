Nebula

A real-time GPU physics simulator built entirely on Vulkan compute shaders — cloth, soft bodies, fluids, sand, snow and smoke in one small C++20 library.

GitHubQuick startExamples

Note: rendered with Blender (seashore waves · city wind · avalanche). See examples/demo/README.md for how to run it.

Why nebula

  • Cross-platform

    Plain Vulkan 1.2 with no vendor-specific extensions, so it is not tied to NVIDIA or to Ubuntu. Exercised on NVIDIA (Linux), Apple GPUs (macOS via MoltenVK) and Mesa lavapipe, a CPU Vulkan driver used by CI.

  • Fast

    Everything — physics, neighbor search, rendering — stays on the GPU. On the same scenes nebula is about 2–6x faster than NVIDIA Warp (Newton) for fluid and sand ([numbers below](#performance)).

  • Many solvers

    XPBD cloth, XPBD tetrahedral soft bodies, Position Based Fluids, MPM (PIC/FLIP/APIC; elastic, Von Mises, Drucker-Prager, fluid), grid-based Pyro (smoke & fire), and cloth↔fluid coupling.

  • Simple dependencies

    No CUDA, no Python runtime, no heavyweight frameworks. Just Vulkan, GLFW and GLM from your package manager; VMA, argparse, doctest and tinyobjloader are fetched by CMake / git submodules.

Quick start

sudo apt install shaderc vulkan-headers vulkan-loader glfw3 libglm-dev   # Ubuntu
brew install shaderc vulkan-headers vulkan-loader molten-vk glfw glm     # macOS

git clone --recursive https://github.com/20niship/nebula.git && cd nebula
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/mpm_avalanche
